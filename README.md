# MSGMailReader

This is a Client-side Outlook MSG-File rendering library and a Sharepoint CustomAction that integrates this library into old SharePoint 2016

## MailReader/ 
MSG-file reading library implemented in TypeScript 

## MailReaderApp/
SharePoint CustomAction feature that integrates the library into old SharePoint 2016 

## MailReaderTest/
A test environment. It is not designed to run on your machine, you will need to adapt this to your own environment
